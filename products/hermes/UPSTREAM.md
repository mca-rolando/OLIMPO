# Upstream and Fork Provenance

HermesDDNS is derived from the MIT-licensed project `benjaminbear/docker-ddns-server`, which itself credits/inherits ideas from `dprandzioch/docker-ddns`.

The original MIT copyright and permission notice is preserved in `LICENSE`.

For the initial fork transition, the source snapshot provided to the HermesDDNS project is retained under `legacy/original-source/`. This directory is reference material and is not part of the active HermesDDNS runtime.

The active HermesDDNS code uses the module path:

```text
github.com/mca-rolando/HermesDDNS
```
